# Guía de Contribución – GrowHardware

¡Gracias por tu interés en contribuir a GrowHardware!
Este proyecto es parte del ecosistema agro-tecnológico abierto del Sur Global,
y tu aporte ayuda a democratizar tecnología de producción y regeneración.

---

## 🚀 Cómo Contribuir

### 1. Hacer Fork y Crear una Rama

1. Haz un fork del repositorio.
2. Crea una nueva rama:
   git checkout -b feature/mi-feature

### 2. Estilo de Código

- TypeScript y Svelte: usar convenciones estándar.
- Evitar lógica innecesaria en el frontend.
- Commits claros y descriptivos.
- Documentar cuando agregues nuevas funcionalidades.

### 3. Cumplimiento de la AGPLv3

Si tus cambios afectan funciones accesibles por red:

- Debes publicar _todo_ el código fuente modificado.
- Las contribuciones deben ser compatibles con AGPLv3.

### 4. Pull Requests

- Asegúrate de actualizar tu rama con `main`.
- Incluye tests cuando sea relevante.
- Explica claramente qué problema resuelve tu PR.

---

## 🧪 Pruebas

- Se recomiendan tests unitarios cuando sea posible.
- Para módulos de dispositivos físicos, utilizar mocks o emuladores.

---

## 🔐 Seguridad

Si encuentras un problema de seguridad:

- **No abras un issue público.**
- Contacta directamente a: **info@growhardware.io**
